# Проверка задачи кандидата по теме sync.WaitGroup (Go)

Пожалуйста, оцени решение кандидата по следующей задаче:

## Задача
Написать программу на Go, которая:
1. Запускает N горутин.
2. Каждая горутина ждёт случайное время (100–500 мс), затем выводит свой ID.
3. Главная горутина использует `sync.WaitGroup`, чтобы дождаться завершения всех горутин.
4. После завершения выводится `"Done"`.

---

## Критерии оценки

### 1. Корректность использования WaitGroup
- Правильно ли вызывается `.Add()` **до** запуска горутин?
- Есть ли вызов `.Done()` в каждой горутине?
- Есть ли вызов `.Wait()` в главной горутине?

### 2. Отсутствие ошибок, приводящих к панике
- Нет ли ошибок типа отрицательного счётчика WaitGroup?
- Нет ли вызова `.Add()` внутри горутины?

### 3. Корректный захват переменных цикла
- Передаётся ли ID горутины как аргумент функции, а не используется переменная цикла напрямую?

### 4. Работа с общими данными
(Если в решении есть общий slice/счётчик)
- Используется ли `sync.Mutex` или канал для защиты конкурентных записей?
- Нет ли потенциальных гонок?

### 5. Логика работы
- Используется ли случайная задержка (`time.Sleep`, `rand.Intn`)?
- Выводятся ли ID горутин?
- Печатается ли `"Done"` после выполнения всех горутин?

### 6. Завершает ли программа работу корректно
- Нет ли возможности deadlock'а?
- Гарантировано ли завершение всех горутин?

---
